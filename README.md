# Office Tools and Learning Games

Free fresh Windows tools for working through batches of documents, photos, and files, six remedial learning spoken games for practicing reading and counting/money, and a Force Account/Change Order cost Excel workbook for South Dakota DOT.

**[Open the page with all games and downloads](https://djt1953.github.io/office-tools-and-learning-games/)**

## Learning games

The games speak out loud and run in a web browser, with nothing to install. Turn the sound on. They were built for adults practicing remedial reading and everyday money/counting skills. Each has a coach panel for adults adjusting the lessons, and progress stays in that browser on that computer.

| Game | Practice | Play |
|---|---|---|
| Word Race | Hear a word, then find it, while racing a rival | [Play](https://djt1953.github.io/office-tools-and-learning-games/games/word-race.html) |
| Oval Showdown | Match words in upper and lower case on an oval track | [Play](https://djt1953.github.io/office-tools-and-learning-games/games/oval-showdown.html) |
| Haunted House Payday | Count out dollar bills and get change back | [Play](https://djt1953.github.io/office-tools-and-learning-games/games/haunted-house-payday.html) |
| Christmas Gift Run | Pay with bills and coins and watch your change | [Play](https://djt1953.github.io/office-tools-and-learning-games/games/christmas-gift-run.html) |
| Menu Run | Read menu words and learn where food comes from | [Play](https://djt1953.github.io/office-tools-and-learning-games/games/menu-run.html) |
| Carol Match | Match real photos to words; each match spells the word aloud and plays a note of a Christmas carol | [Play](https://djt1953.github.io/office-tools-and-learning-games/games/carol-match.html) |

[Download all six games](https://github.com/DJT1953/office-tools-and-learning-games/releases/latest/download/learning-games.zip) to play without an internet connection. The fonts need internet, and plain fonts are used without it.

Carol Match's photos come from Wikimedia Commons and keep their own licenses (public domain, CC0, CC BY and CC BY-SA), listed in the game's Photo credits and in [the photo credits](docs/games/carol-match-photos/CREDITS.md).

## Windows tools

Unzip any tool below, then start it as shown. Your originals are left alone unless a tool's instructions say otherwise, but keep a backup when working on important files.

Or use a tool's **Easy installer**: one Setup file that sets it up with everything else it needs (except Microsoft Word, where a tool needs it) and adds it to the Start menu. The installers are not code-signed, so Windows may show "Windows protected your PC": click More info, then Run anyway. Each tool's **Check for updates** button opens [the page with all of them](https://djt1953.github.io/office-tools-and-learning-games/).

**To update a tool**, run its new Easy installer. There is no need to uninstall the old one first: the installer replaces it and keeps your settings. For a zip, unzip the new one into the same place and choose **Replace the files in the destination**.

**Music Player needs:** Windows 10 or 11 and [Python 3.10 or newer](https://www.python.org/downloads/windows/) (tested with 3.14); if the PC has none, `Run_MusicPlayer.bat` offers to install it. The first time it starts, it offers to download and install its free add-ons, about 190 MB (less if the Video Player or Video Editor is already set up): [PySide6](https://pypi.org/project/PySide6/), [Mutagen](https://pypi.org/project/mutagen/), [imageio-ffmpeg](https://pypi.org/project/imageio-ffmpeg/), [winrt-Windows.Media.Control](https://pypi.org/project/winrt-Windows.Media.Control/), [winrt-Windows.Media](https://pypi.org/project/winrt-Windows.Media/) and [pycaw](https://pypi.org/project/pycaw/). Radio needs an internet connection; the stations come from [Radio Browser](https://www.radio-browser.info/). Spotify is optional and needs the Spotify app ([Microsoft Store](https://apps.microsoft.com/detail/9ncbcszsjrsb) or [spotify.com](https://www.spotify.com/download/windows/)) and a free or Premium Spotify account. The zip's `How to use.txt` has the same list.

**Book Reader needs:** Windows 10 or 11 and [Python 3.10 or newer](https://www.python.org/downloads/windows/) (tested with 3.14); if the PC has none, `Run_BookReader.bat` offers to install it. The first time it starts, it offers to download and install its free add-ons, about 200 MB (less if the Music Player, Video Player or Video Editor is already set up): [PySide6](https://pypi.org/project/PySide6/), [lxml](https://pypi.org/project/lxml/) and [comtypes](https://pypi.org/project/comtypes/). Look up needs an internet connection; meanings come from the [Free Dictionary API](https://dictionaryapi.dev/), and Look it up on the web opens [Wiktionary](https://en.wiktionary.org/). Saving a copy as Word needs [Microsoft Word](https://www.microsoft.com/microsoft-365/word). The Free books button opens [Project Gutenberg](https://www.gutenberg.org/) or [Standard Ebooks](https://standardebooks.org/ebooks) in the web browser; both give books away free with no account needed. Read aloud uses the voices that come with Windows. Books locked with copy protection (most bought from Amazon) are listed but can't be opened; the Book Reader never removes copy protection. The zip's `How to use.txt` has the same list.

**Proofreader needs:** Windows 10 or 11. Double-click `Install_Proofreader.bat` once and it installs everything except Microsoft Word, asking first before it installs Python: [Python 3.10 or newer](https://www.python.org/downloads/windows/) if the PC has none (tested with 3.14), the free add-ons [PySide6](https://pypi.org/project/PySide6/), [comtypes](https://pypi.org/project/comtypes/) and [python-docx](https://pypi.org/project/python-docx/) (about 200 MB, less if the Book Reader, Music Player, Video Player or Video Editor is already set up), the free checker [LanguageTool](https://languagetool.org/) with its own copy of [Java (Eclipse Temurin 17)](https://adoptium.net/) (about 300 MB), and a Desktop shortcut. After that no internet is needed and no document text leaves the computer. [Microsoft Word](https://www.microsoft.com/microsoft-365/word) is optional: with it, Word's checker runs second and .doc and .rtf documents can be corrected; without it, .docx and .txt documents are still corrected by the free checker alone. While it works, the free checker uses up to 4 GB of memory on computers with 16 GB or more, 2 GB on 8 GB computers and 1 GB on smaller ones. English (United States) only. The zip's `How to use.txt` has the same list.

**Song Cleaner needs:** Windows 10 or 11. Double-click `Install_SongCleaner.bat` once and it installs everything, asking first before it installs Python: [Python 3.10 or newer](https://www.python.org/downloads/windows/) if the PC has none (tested with 3.14), the free add-ons [PySide6](https://pypi.org/project/PySide6/), [numpy](https://pypi.org/project/numpy/), [mutagen](https://pypi.org/project/mutagen/) and [imageio-ffmpeg](https://pypi.org/project/imageio-ffmpeg/), which brings [FFmpeg](https://ffmpeg.org/) (about 300 MB to download, less if the Music Player, Book Reader, Proofreader, Video Player or Video Editor is already set up), and a Desktop shortcut. Optional: looking up doubtful song names online uses the free song recognizer [Chromaprint fpcalc](https://acoustid.org/chromaprint) (about 4 MB; the installer asks) and a free key from [AcoustID](https://acoustid.org/); only a song's sound fingerprint and length are sent, never the file. Everything else works offline. MP3 files only; other sound files are left alone. The zip's `How to use.txt` has the same list.

**Photo Stitcher needs:** Windows 10 or 11 and [Python 3.10 or newer](https://www.python.org/downloads/windows/) (tested with 3.14); if the PC has none, `Run_PhotoStitcher.bat` offers to install it. The first time it starts, it offers to download and install its free add-ons, about 72 MB: [OpenCV](https://pypi.org/project/opencv-python-headless/), which finds the matching details and joins the photos, [numpy](https://pypi.org/project/numpy/), [Pillow](https://pypi.org/project/pillow/) and [pillow-heif](https://pypi.org/project/pillow-heif/), which opens iPhone HEIC photos. After that no internet is needed. Very big panoramas need a lot of memory; if the computer runs short, the photos are joined at a smaller size and it says so. The zip's `How to use.txt` has the same list.

**Photos to Word needs:** Windows 10 or 11 and [Python 3.10 or newer](https://www.python.org/downloads/windows/) (tested with 3.14); if the PC has none, `Run_PhotoText.bat` offers to install it. The first time it starts, it offers to download and install its free add-ons: [Pillow](https://pypi.org/project/pillow/), [python-docx](https://pypi.org/project/python-docx/) and [pytesseract](https://pypi.org/project/pytesseract/), then the reader that reads print and handwriting, [RapidOCR](https://pypi.org/project/rapidocr/) with [onnxruntime](https://pypi.org/project/onnxruntime/) and its data, about 120 MB in all, once. The reading happens on the computer; nothing is uploaded. Without RapidOCR, [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) can read printed pages instead. iPhone HEIC photos need [pillow-heif](https://pypi.org/project/pillow-heif/), which the zip's `Run_PhotoText.bat` installs.

**Dating Photographs needs:** Windows 10 or 11 and [Python 3.10 or newer](https://www.python.org/downloads/windows/) (tested with 3.14); if the PC has none, `Run_DatingPhotos.bat` offers to install it. The first time it starts, it offers to download and install its free add-ons, about 120 MB with the reader's data: [Pillow](https://pypi.org/project/pillow/), [RapidOCR](https://pypi.org/project/rapidocr/), which reads the handwriting, [onnxruntime](https://pypi.org/project/onnxruntime/) and [pytesseract](https://pypi.org/project/pytesseract/). After that no internet is needed; nothing is uploaded. [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) is optional and helps with printed words. The list of moves it keeps opens in Excel. The zip's `How to use.txt` has the same list.

No Python on the PC? Each tool's start file (the `.bat` file in the table) offers to install it, free from python.org, or get [Python 3.10 or newer](https://www.python.org/downloads/windows/) yourself; the tools are tested with 3.14. The **Easy installer** needs no Python at all. The tools install any free add-ons they need the first time they run, which takes an internet connection.

## SDDOT force account workbook

An Excel workbook that totals labor, materials, equipment, overhead, profit, the prime contractor's administrative allowance, and excise tax under Section 9.4 D of the South Dakota DOT specifications.
[Download the workbook](https://github.com/DJT1953/office-tools-and-learning-games/releases/latest/download/sddot-force-account-workbook.zip)

It is an independent aid, not affiliated with or endorsed by the South Dakota Department of Transportation. Confirm it against your own contract and with your Engineer before relying on its figures. The `Inputs` tab lists the places where the specification leaves room for interpretation.
