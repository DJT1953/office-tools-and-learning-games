Windows tools

For working through batches of documents, photos and files. Each download includes how to start it; see the full list.

Easy installer sets the program up with everything else it needs, except Microsoft Word where a card says so, and adds it to the Start menu. Download zip gives just the program's files, which need what each card lists. The installers are not code-signed, so Windows may show "Windows protected your PC": click More info, then Run anyway. Each program's Check for updates button opens this page.

To update a program, run its new Easy installer. There is no need to uninstall the old one first: the installer replaces it and keeps your settings. For a zip, unzip the new one into the same place and choose Replace the files in the destination.

  • Proofreader

    Fixes spelling, grammar, punctuation, spacing and capital letters in batches of Word (.doc, .docx), .rtf and .txt documents, or whole folders. One press of Start runs each document through two checkers, one after the other: the free LanguageTool, then Microsoft Word's own. Corrected copies and a report of every change are saved beside the originals, doubtful fixes are listed for you instead of guessed, and swear words are never changed. Pause any time, and pick up where you left off next time. Works without Microsoft Word too.

    Needs Windows 10 or 11. Install_Proofreader.bat installs everything else, asking before it installs Python 3.10 or newer: the free add-ons PySide6, comtypes and python-docx, and the free checker LanguageTool with its own Java; about 500 MB in all.

    Microsoft Word is optional: without it, .docx and .txt documents are still corrected; .doc and .rtf need Word. Uses up to 4 GB of memory while it works (less on smaller computers). English (United States) only.

    Easy installerDownload zip

  • Song Cleaner

    Tidies a folder of MP3 songs recorded from the radio: fixes their names (DJ tags, copy numbers, cut-off titles, odd spellings), finds copies of the same recording by their sound and keeps the fullest, and trims silence, talk and noise from the ends without lowering the sound quality. Every change is shown first with Play buttons, nothing is deleted, and Undo puts it all back.

    Needs Windows 10 or 11. Install_SongCleaner.bat installs everything else, asking before it installs Python 3.10 or newer: the free add-ons PySide6, numpy, mutagen and imageio-ffmpeg with FFmpeg; about 300 MB in all.

    Optional: to look up doubtful names online, the free Chromaprint fpcalc (the installer asks) and a free AcoustID key. MP3 files only.

    Easy installerDownload zip

An optional Adjust window turns, straightens, squares up, crops and resizes it into a separate copy. Opens JPG, PNG, TIFF, BMP, WebP and iPhone HEIC photos; your photos are never changed.

    Needs Windows 10 or 11 and Python 3.10 or newer; the zip's start file offers to install it. The first time it starts, it offers to install the free add-ons OpenCV, numpy, Pillow and pillow-heif; about 72 MB. The Easy installer has everything it needs.

You check every date first. It can also set each photo's Date taken and print the date on it in orange like a film camera, keeping an untouched copy; Undo puts everything back.
